// The trust split

Every feature, labeled honestly.

Google's Indexing API is officially restricted to JobPosting and BroadcastEvent content — not ordinary pages. There's no public API for GSC's Removals tool at all. Tools that offer "bulk Google indexing" and "bulk removal" for any URL are automating the web UI, whether they tell you or not. We tell you.

// FAQ

Before you ask support.

Is bulk Google indexing actually guaranteed to work?+
No — and we'd rather say that here than have you find out from a support ticket. It automates the real Search Console UI in your logged-in tab, which Google can change at any time. We monitor for breakage and ship fixes fast, but we don't control Google's side.
Will this get my Google account flagged?+
The automated features carry real risk of Google flagging automated-looking activity — we pace actions conservatively by default and stop immediately on any CAPTCHA rather than trying to bypass it, but we can't eliminate the risk entirely. The API-backed features (inspection, reporting, IndexNow) carry none of this risk.
Why isn't Google bulk-indexing an official feature anywhere?+
Google's Indexing API is restricted to JobPosting and BroadcastEvent content by design — it was never meant for general pages. Any tool claiming otherwise is either misusing that API or automating the UI like we are, openly.
